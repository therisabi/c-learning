1. Назначение
Консольное приложение на C для управления списком задач с сохранением состояния между запусками программы в локальном файле.

2. 
main - рендер меню и карточек с задачами. точка входа

control - CRUD-функции управления

storage - сохранение созданных карточек в текстовый файл (с разделителями)s

structure.h - основной заголовочный файл
